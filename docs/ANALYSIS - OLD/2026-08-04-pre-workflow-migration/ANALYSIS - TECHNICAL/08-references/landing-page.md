# Landing Page Reference

> **In plain terms:** This reference summarizes the future first-page plan and points to its detailed records. It does not claim a route or page was implemented.

**Status:** Planned documentation only. No landing-page code, route, authentication change, or system test has been performed.

The future public landing page is defined in the [technical plan](../03-planning/landing-page.md). It will use Bootstrap as the primary layout and component framework, with minimal template-consistent custom CSS only where necessary.

The planned page contains navigation, hero, about, services, testimonials, login and registration calls to action, and a footer. A separately approved implementation may replace the unauthenticated root redirect with the landing page, while preserving `/auth/login`, `/auth/register`, authenticated dashboard redirects, and protected routes.
