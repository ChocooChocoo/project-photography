# Glossary

This list explains project words in ordinary language and says why each one matters to the people using the website.

| Word | Meaning | Why it matters here |
| --- | --- | --- |
| Booking | A customer’s request for a photography service | It connects the customer, provider, payment, assignment, and photos |
| Gallery | The online place where a customer receives photos | It is how finished photos are delivered and viewed |
| Payment notice | A message from a payment company confirming an outcome | It helps the website confirm whether a payment event is valid |
| Sample data | Practice information used to test the website | It lets important workflows be checked without using real customer records |
| Permission | A rule that controls what a person can open or change | It keeps each staff member within their allowed work |
| Subscription | A studio’s plan for using the platform | Its end-of-plan access rules still need a business decision |
