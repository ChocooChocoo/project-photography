# Glossary

| Word | Meaning |
| --- | --- |
| Booking | A customer’s request for a photography service |
| Gallery | The online place where a customer receives photos |
| Payment notice | A message from a payment company confirming an outcome |
| Sample data | Practice information used to test the website |
| Permission | A rule that controls what a person can open or change |
| Subscription | A studio’s plan for using the platform |
