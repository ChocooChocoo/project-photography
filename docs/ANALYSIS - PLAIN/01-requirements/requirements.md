# Plain-Language Requirements

1. Keep an honest record of early roadmap work and its progress.
2. Continue the original Phase 3 work without pretending unfinished items are complete.
3. Provide realistic sample data that uses Cavite locations and keeps records connected correctly.
4. Provide a safe photography-related help assistant that does not expose private information or answer unrelated requests.
5. Keep uploaded images and other media visible both locally and after deployment.
6. Refresh sample data while protecting the existing user and location records and avoiding media references in the fresh sample data.
7. Study what should happen when an assigned photographer cancels, before building a remedy.
8. Study what should happen when a studio subscription ends, before building access restrictions.

See [task records](../04-tasks/index.md) and the [roadmap](../05-roadmap/detailed-roadmap.md).
