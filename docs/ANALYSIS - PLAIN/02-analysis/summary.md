# System Analysis in Plain Language

Platinum is a photography-service website. Clients can choose a studio or freelancer, make a booking and payment, receive photos through an online gallery, and leave a review. Studio owners, photographers, HR, finance staff, freelancers, and administrators have separate work areas.

The complete plain-language story is in [full system analysis](system-analysis.md). Related decisions are in [open questions](../00-overview/open-items.md).
