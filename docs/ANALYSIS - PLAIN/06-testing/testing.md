# Testing in Plain Language

The project checks that sample data remains safe and connected, uploaded files appear where expected, payment notices reject invalid messages, staff pages are available only to the right people, and the photography assistant handles unsafe or unrelated requests safely.

The latest recorded full check passed 70 tests with 383 checks on 2026-08-01. This proves the checked behavior at that time; it does not replace a business decision that has not been made.
