# Planning Architecture

> **In plain terms:** Approved changes should extend the Laravel workflows already in the project. A new parallel application or duplicate workflow is outside this plan.

Reuse the existing Laravel portal boundaries, Eloquent models, migrations, Blade templates, and service layer. New work must extend the current workflow instead of adding a parallel route, state model, or client application. Any schema or workflow change needs a user-authored task and traceability entry before implementation.
