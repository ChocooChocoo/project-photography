# Roadmap in Plain Language

The roadmap now has twelve stages. It begins with fixing broken features, continues through unfinished and advanced work, then covers automation, testing, the photography assistant, cancellation planning, subscription planning, the documented future first page, and planned studio-management improvements. The two new stages are not website work yet; the current login page remains the first page until a separate implementation task is approved.
