# Planned First Page

**Status:** This is a plan only. The website has not changed.

The website still opens on the existing login page. A future improvement will give visitors a welcoming first page before they sign in. It will explain what the Platinum Studio Platform is for and help people decide whether to log in or create an account.

The planned page will have a menu, a main introduction, an about section, a services section, customer comments, clear buttons for login and registration, and a footer. It will work well on computers, tablets, and phones.

The future page will use Bootstrap, a common website layout tool, so its sections, buttons, spacing, and mobile layout look consistent. Small extra design adjustments may be used only when the chosen page design truly needs them.

When the feature is approved for development, the new page should become the first public page. The current login and registration pages will stay available, and sign-in and registration buttons will lead visitors there. The existing account, login, and protected-page behavior must continue working as it does today.

This document records a future improvement. No landing page, routing change, login change, or system test was performed.
