# Planned Studio Management Requirements Reference

This reference lists future improvements requested for the platform. It does not mean they have been built.

The future system should collect complete registration details, protect administrator access with a separate sign-in page and emailed security code, and verify permits before a studio fully operates. Administrators should be able to review documents, give consistent rejection reasons, track repeat submissions, and email approved owners.

It should guide new users, safely provide employee accounts, require employees to replace temporary passwords, support combined job roles, and archive records instead of permanently deleting them. It should also support daily work schedules, camera-and-location attendance checks, client favorites, visible images, and owner-chosen prices and discounts.

The system must not force an automatic discount and must not permanently delete ordinary records. These are future requirements, not current website behavior.
