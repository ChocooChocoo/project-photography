# Objective: Photography Booking Platform Feature and UI Updates

## Goal
Make a set of design, booking, notification, and photographer-management improvements to the photography booking platform.

## Success Criteria
- The landing page looks glamorous and attractive on desktop and on mobile.
- Each package can have its own discount, independent of the studio.
- The messages icon is in the navigation bar, not the sidebar.
- Clients can see camera specs before they book.
- The tutorial explains the platform clearly instead of only listing steps.
- All prices show the peso sign (₱).

## Context
- The platform has studios, packages, clients, photographers, freelancers, and owners.
- Discounts are currently set per studio.
- The messages icon is currently in the sidebar.
- Camera specs are currently visible only after a client books.
- The tutorial is currently a step-by-step list.
- Bookings are either fixed-duration or flexible-duration, and stores have set operating hours.

## Tasks
### Landing Page and UI
- Redesign the landing page to look glamorous and visually attractive.
- Improve the landing page UI for mobile devices.
- Move the messages icon from the sidebar to the navigation bar.
- Rework the tutorial so it is clearer, not just a step-by-step list.
- Show prices in pesos (₱) everywhere.

### Packages and Booking
- Allow a separate discount for each package instead of one discount per studio.
- Show camera specs to clients before booking.
- Remove the end time field from fixed-duration bookings.
- Allow flexible-duration bookings to go past store closing hours.

### Photographers and Freelancers
- Add photographer geolocation.
- Send a push notification or email when the photographer arrives on site.
- Allow multiple freelancers to work under one shared group name.
- Let photographers cancel a job while already on site.
- Let the owner assign a replacement photographer to finish a job after the original photographer cancels.

### Photo Delivery
- Add a before-and-after slider that compares the raw photo with the edited photo.

## Open Questions
- What visual style or reference does "glamorous" mean for the landing page?
- What is photographer geolocation for: live tracking, showing location to clients, or confirming arrival?
- Should on-site alerts go out by push notification, email, or both? Who receives them: the client, the owner, or both?
- How is on-site arrival detected: automatically through geolocation or by the photographer checking in?
- Does a flexible-duration booking have any upper limit once it goes past store hours?
- Does an on-site cancellation have conditions, such as requiring a reason or affecting payment?
- In a freelancer group, how are bookings, payments, and reviews shared or split among members?
