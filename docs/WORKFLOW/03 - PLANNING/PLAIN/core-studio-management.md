# Planned Studio Management Improvements

**Status:** This is a plan only. The website has not changed.

Task 10 collects the improvements requested for a future version of the platform. The plan covers better registration, safer administrator access, business-permit checks, clearer approval work, employee accounts, roles, attendance, booking browsing, and owner-controlled prices.

Future registration will collect complete studio and owner details, including services, price ranges, role details, down-payment choices, and more social links. Administrators will have their own sign-in page with an emailed security code. They will be able to review permits, use consistent rejection reasons, count repeat submissions, and email approved owners.

Businesses should not fully set up their studio until their permit is verified. Expired permits should need checking again. New users will receive an optional guide, while new employees will receive temporary sign-in details and must choose a new password the first time they use the system.

The future system should let one person hold combined responsibilities, make permission choices easier, keep deleted records safely archived, support different work hours for each day, and use both a live camera photo and location check for attendance. Clients will be able to save favorite studios and clearly see package and gallery images. Studio owners, not the system, will decide their own discounts.

No mandatory automatic discount and no permanent deletion are included. A later approved task must decide the build order and make these changes safely.
