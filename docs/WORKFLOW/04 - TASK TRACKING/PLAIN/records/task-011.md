# TASK-011 — Phase 4 Workflow Improvements

> **In plain terms:** This task records the completed improvements that make bookings clearer for customers, freelancers, and studios.

**Source:** [`prompt/tasks/11.md`](../../../../../prompt/tasks/11.md)
**Status:** Completed through Phase 4.5 on 2026-08-04.
**What changed:** Customers can see the photographer assigned to a studio booking and receive a notice that names them. Freelancers respond to their own bookings. Eligible premium studios say Featured. Customers can add a landmark or directions for an on-location shoot.
**Evidence:** [Phase 4 roadmap](../../../05%20-%20ROADMAP/PLAIN/roadmap.md), [progress tracker](../../../06%20-%20PROGRESS%20TRACKING/PLAIN/tracker.md), [technical audit](../../../../../prompt/audits/11-phase-4-workflow-improvements-technical-audit.md), [plain-language audit](../../../../../prompt/audits/11-phase-4-workflow-improvements-plain-language-audit.md), and the complete automated test run (89 tests, 447 checks).

**Not added:** A public portfolio page for an individual studio photographer and email notices, because the current system has neither and the task did not require building them.
