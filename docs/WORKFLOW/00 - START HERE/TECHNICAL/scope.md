# Scope and Evidence Rules

This documentation covers the existing Platinum Laravel application, its requirements, plans, user-authored tasks, progress, tests, diagrams, and supporting references.

The project is **Mode A — Existing** because working application code and a database are present. Records distinguish evidence-backed current behavior from planned work, unresolved decisions, blockers, risks, assumptions, and suggestions.

This documentation migration does not authorize application changes. Implementation requires an approved user-authored task, requirement traceability, and evidence of completion.
