# Scope and Evidence Rules

This documentation describes the existing Platinum platform, its requirements, plans, tasks, progress, tests, diagrams, and supporting references.

The project is **Mode A — Existing** because working application code and a database exist. Records describe what is evidenced in the project separately from what is planned, undecided, blocked, or only suggested.

The current records do not authorize application changes. A task, requirement, recommendation, or open question becomes implementation work only when the project owner approves it and the required evidence is recorded.
