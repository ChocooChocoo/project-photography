# Glossary

| Technical term | Plain-language meaning |
| --- | --- |
| Blade | Laravel’s server-generated page template system |
| Portal | The part of the website shown to one type of user |
| Middleware | A checkpoint that allows or blocks a web request |
| Migration | A versioned database-structure change |
| Seeder | A tool that fills the database with sample or starting data |
| Webhook | A message sent by a payment provider to confirm an event |
| Public disk | The configured location for website-visible uploads |
| Traceability | Links showing how a request connects to work and proof |
