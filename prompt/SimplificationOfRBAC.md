Objective: Simplify RBAC Terminology for Better User Understanding

    The current Role-Based Access Control (RBAC) system is functioning correctly in terms of logic, processes, and workflows. However, the terminology used within the system is highly technical and may not be easily understood by non-technical users.

    For example, role names such as “owner-super-admin” are considered IT jargon and can be confusing for general users.

Goal:
    Revise and simplify RBAC role names and terminology to make them more intuitive and    user-friendly, without modifying the existing logic, permissions, or system behavior.

Key Requirements:
    - Maintain all current RBAC logic, structure, and access rules
    - Only update labels, names, and displayed terminology
    - Use clear, simple, and non-technical language
    - Ensure consistency across the system (UI, forms, dashboards, etc.)

Expected Outcome:
    Users—especially non-technical ones—can easily understand roles and permissions, improving usability and reducing confusion, while the underlying RBAC system continues to function exactly as before.
