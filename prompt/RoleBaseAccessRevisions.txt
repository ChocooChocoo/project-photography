## **Scenario: Web Application RBAC**

### Step 1️⃣ Define Roles

| role_id | name   | description               |
| ------- | ------ | ------------------------- |
| 1       | Admin  | Full access to system     |
| 2       | Editor | Can create and edit posts |
| 3       | Viewer | Can view content only     |

---

### Step 2️⃣ Define Permissions

| permission_id | name           | description          |
| ------------- | -------------- | -------------------- |
| 1             | create_user    | Can create new users |
| 2             | edit_user      | Can edit users       |
| 3             | delete_user    | Can delete users     |
| 4             | create_post    | Can create posts     |
| 5             | edit_post      | Can edit posts       |
| 6             | delete_post    | Can delete posts     |
| 7             | view_dashboard | Can view dashboard   |

---

### Step 3️⃣ Link Roles to Permissions (`tbl_role_permissions`)

| role_id | permission_id |                         |
| ------- | ------------- | ----------------------- |
| 1       | 1             | Admin → create_user     |
| 1       | 2             | Admin → edit_user       |
| 1       | 3             | Admin → delete_user     |
| 1       | 4             | Admin → create_post     |
| 1       | 5             | Admin → edit_post       |
| 1       | 6             | Admin → delete_post     |
| 1       | 7             | Admin → view_dashboard  |
| 2       | 4             | Editor → create_post    |
| 2       | 5             | Editor → edit_post      |
| 3       | 7             | Viewer → view_dashboard |

---

### Step 4️⃣ Assign Roles to Users (`tbl_user_roles`)

| user_id | role_id |                |
| ------- | ------- | -------------- |
| 101     | 1       | John → Admin   |
| 102     | 2       | Maria → Editor |
| 103     | 3       | Steve → Viewer |

---

### Step 5️⃣ How the RBAC Works in Action

#### Example 1: John tries to delete a user

* John’s roles → Admin
* Admin’s permissions → includes `delete_user`
  ✅ Allowed

#### Example 2: Maria tries to delete a user

* Maria’s roles → Editor
* Editor’s permissions → `create_post`, `edit_post`
  ❌ Not allowed

#### Example 3: Steve tries to view the dashboard

* Steve’s roles → Viewer
* Viewer’s permissions → `view_dashboard`
  ✅ Allowed

---

### Step 6️⃣ Why This Works

1. Users **never get permissions directly**.
2. Roles **bundle permissions**.
3. Users **inherit permissions automatically** from roles.
4. Adding a new permission or role doesn’t break existing assignments.
