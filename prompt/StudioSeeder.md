**Objective: Seeder for Studio Creation Along With Their Employees**

1. **Studio Seeder Creation**
   Create a seeder for studio creation. Generate at least **3–4 studios**, and make them **already verified or approved by the admin** to reduce manual processing.

2. **Studio Owner Relationship**
   Every studio must have a **Studio Owner**. Ensure that the **database constraints and relationships** are properly defined and accurate.

3. **Employee Assignment Per Studio**
   For every studio, create the following employees:

   * **1 Studio Owner**
   * **5 Studio HR**
   * **5 Studio Finance**
   * **5 Studio Photographer**

   For both **HR** and **Finance**, there should only be:

   * **1 Manager**
   * **4 Staff**

4. **Schedules and Packages**
   Every **studio** and every **employee** must have schedules.
   Also, add packages for every studio.

   For the packages:

   * Each package must have **3 types** such as **Basic, Essentials, Premium**, or similar.
   * The package types should still be **based on the package itself**, meaning they are **not fixed** and can vary depending on the package structure.
