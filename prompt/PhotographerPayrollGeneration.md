### **Enhanced Objective: Studio Photographer Payroll Generation (Attendance + Booking-Based)**

1. **Current Payroll Structure**
   The existing payroll system for studio staff (e.g., HR and Finance personnel) is based solely on **attendance**. Compensation is calculated depending on the number of days or hours worked.

2. **Proposed Payroll Structure for Studio Photographers**
   Unlike other roles, studio photographers have a dual contribution model. Therefore, their payroll should be computed based on **two key factors**:

   * **Attendance** – compensation for time rendered (e.g., daily or hourly rate)
   * **Successful/Completed Bookings** – additional earnings tied to performance (e.g., per completed shoot)

3. **Objective Enhancement**
   Develop and implement a payroll system for studio photographers that integrates both:

   * **Fixed earnings** from attendance, and
   * **Variable earnings** from successfully completed bookings

   This ensures a fair and performance-driven compensation structure that:

   * Rewards consistency (attendance)
   * Incentivizes productivity and output (completed bookings)

4. **Expected Outcome**
   A payroll system that accurately calculates total compensation for studio photographers using the formula:

   **Total Pay = Attendance-Based Pay + Booking-Based Pay**
