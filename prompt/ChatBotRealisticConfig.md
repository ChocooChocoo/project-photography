**Objective: Create a Realistic Chatbot Configuration for Conversations**

1. Create a chatbot configuration for greeting clients in a natural and professional way when a chat starts.

2. Create a configuration for detecting and filtering bad words, spam, and unnecessary messages to maintain clean and appropriate conversations.

3. Create a configuration for handling common client inquiries, such as booking, pricing, services, and other related questions.

4. Create a configuration for quick replies so the chatbot can respond faster and provide consistent answers to frequently asked questions.

5. Instead of using manual input for these configurations, store and initialize them using Laravel seeders.

**Expected Outcome:**
The chatbot should have a realistic conversation flow, proper message filtering, structured inquiry handling, and ready-to-use quick replies, with all initial configuration data managed through Laravel seeders for easier setup and maintenance.
